# 试香吧 · 自助试香终端 前端演示版

微信小程序 C 端的**纯前端样式演示**：不依赖任何构建工具和后端服务，所有接口由 `js/mock.js` 模拟。

## 如何预览

直接双击打开 `index.html`（推荐 Chrome / Edge），浏览器中会以手机壳居中展示；窗口缩到手机宽度时自动全屏。

也可用本地服务器打开（可选）：

```bash
cd 香水/frontend
python -m http.server 8080   # 或 npx serve
# 访问 http://127.0.0.1:8080
```

## 演示主流程

1. 首页（模拟扫码进入）：终端信息 + 20 款香型宫格（含售罄/维护中状态）；
2. 点香型卡片 → 详情页：前中后调、试香须知；
3. 「¥0.5 立即试香」→ 模拟微信支付 → 喷雾页；
4. 第一次点喷雾按钮：先播放「酒精冲洗管路 2~3 秒」动画（对应 PRD HW-02），再开始喷射；
5. 喷射次数 5 → 0 递减（雾化粒子动画），用完自动进入完成页；
6. 完成页自动发放「满 20 减 3」优惠券 → 「用券下单正装」；
7. 下单页：地址、优惠券选择（点券行可切换用/不用）、价格试算 19.9 − 3 = 16.9 → 模拟支付；
8. 订单页：试香记录 / 正装订单双 Tab；未使用的试香凭证可在喷雾页申请退款；
9. 「我的」页：优惠券列表；**重置演示数据**可清空所有订单恢复初始状态。

订单、优惠券数据存于浏览器 localStorage，刷新不丢；清缓存或点「重置演示数据」即恢复初始。

## 文件说明

| 文件 | 职责 |
| ---- | ---- |
| `index.html` | 入口：手机壳、状态栏、导航栏、Tab 栏、全局浮层 |
| `css/style.css` | 全部样式（主题：藕紫 + 奶油底 + 金色点缀） |
| `js/mock.js` | **Mock 后端**：20 款香型数据、订单状态机、优惠券、localStorage 持久化（接口清单见《接口文档.md》） |
| `js/api.js` | **统一 API 层**：页面唯一数据出口；接真实后端只改这个文件 |
| `js/app.js` | hash 路由 + 7 个页面渲染与交互 |

## 接真实后端 / 迁移微信小程序

- 接后端：只改 `js/api.js` 内部实现（`MockBackend.call` → `fetch`），页面代码零改动；
- 迁移小程序：`app.js` 中所有 `TODO(wx)` 注释处替换为微信能力（`wx.requestPayment` 等）；
- 接口契约：见 `../lcyperson/自产文件/接口文档.md`，改接口先改文档再改 `mock.js`。
