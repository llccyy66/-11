## 零、通用约定

### 0.1 响应结构

```json
{ "code": 0, "msg": "ok", "data": { } }
```

| code | 含义 |
| ---- | ---- |
| 0 | 成功 |
| 400 | 参数缺失/非法 |
| 404 | 资源不存在（香型 / 订单 / 优惠券） |
| 409 | 业务状态冲突（售罄、已用完、不可退款等） |
| 500 | Mock 内部异常 |

### 0.2 Mock 行为特性

- 所有接口模拟 **250~550ms 随机网络延迟**；
- **支付接口默认成功**（真实环境替换为微信支付 `wx.requestPayment`，见各接口 `TODO(wx)` 注释）；
- 可变数据（试香订单、正装订单、优惠券）持久化在浏览器 **localStorage（key: `ptf_mock_db_v1`）**，刷新不丢失；
- 演示数据重置：`POST /api/dev/reset` 或前端「我的 → 重置演示数据」。

### 0.3 核心状态机

**试香订单**（`trialOrder.status`）：

```
pending_pay（待支付）→ paid（已支付/试香中）→ finished（5喷用完或手动完成）
pending_pay / paid(未喷射) → refunded（已退款）
```

**正装订单**（`shopOrder.status`）：

```
pending_pay（待支付）→ paid（已支付/配送中）→ done（已完成，Mock 不自动流转）
```

**优惠券**（`coupon.status`）：`valid → used`（下单支付成功时核销）

### 0.4 关键业务常量（改价格/次数改这里）

| 常量 | 值 | 位置 | 说明 |
| ---- | ---- | ---- | ---- |
| `TRIAL_PRICE` | 0.5 | mock.js | 单次试香价格 |
| `SPRAY_TOTAL` | 5 | mock.js | 单次凭证喷射次数 |
| 优惠券面额 | 满 19 减 3，7 天有效 | mock.js 接口 9 | 试香完成自动发放（门槛 19 覆盖全部 19.9 元起商品） |
| 香型数据 | 20 款（f01~f20） | mock.js `FRAGRANCES` | 含前中后调、价格、状态、封面渐变色 |

```json
  "terminal": { "id": "T-003", "code": "A03", "name": "图书馆 2F 试香终端", "location": "河北师范大学 · 图书馆 2F 电梯旁", "status": "online" },

  "trialPrice": 0.5,
  "sprayTotal": 5
}
```

**Mock 说明**：固定返回 `TERMINAL` / `USER` 常量；`status` 可手动改为 `offline` 验证维护态。

### 2. `GET /api/terminals/:code` — 终端状态（MP-01 / HW-10）

**入参**：路径参数 `code`（终端编号）。

**返回 data**：同上 `terminal` 对象。

**Mock 说明**：目前与扫码接口同源，用于喷雾前刷新终端在线状态。

## 三、试香订单

### 5. `POST /api/trial/orders` — 创建试香订单（MP-04）

**入参**

```json
{ "fragranceId": "f01", "terminalCode": "A03" }
```

**返回 data**

```json
{
  "id": "TB1001",
  "fragranceId": "f01", "fragranceName": "晨雾柑橘", "emoji": "🍊", "grad": ["#f6b56b", "#f48c5e"],
  "terminalCode": "A03",
  "amount": 0.5,
  "sprayTotal": 5, "sprayLeft": 5, "sprayUsed": 0,
  "status": "pending_pay",
  "createdAt": 1760000000000
}
```

**业务规则**：香型 `status ≠ ok` 时返回 `409`（售罄/维护中不可下单）。

### 6. `POST /api/trial/orders/:id/pay` — 试香支付（MP-04）

**入参**：路径参数 `id`。

**返回 data**：完整试香订单（同接口 5），支付后 `status: "paid"`、`paidAt`、`expiresAt`（当前时间 + 24h，凭证当日有效）。

**Mock 说明**：默认直接成功。`TODO(wx)`：真实环境由小程序拉起 `wx.requestPayment`，支付回调置 `paid`。

### 7. `GET /api/trial/orders/:id` — 试香订单详情（MP-05 / MP-06）

**入参**：路径参数 `id`。

**返回 data**：完整试香订单对象。用于喷雾页恢复状态（剩余次数、是否已完成/退款）。

### 8. `POST /api/trial/orders/:id/spray` — 触发喷射（MP-05 / HW-02 / HW-04 / HW-05）

**入参**：路径参数 `id`。

**返回 data**

```json
{ "orderId": "TB1001", "needFlush": true, "sprayLeft": 4, "sprayUsed": 1, "status": "paid" }
```

**业务规则**

- 订单必须 `status = paid`，否则 `409`；
- `sprayLeft = 0` 时返回 `409 喷射次数已用完`；
- **`needFlush: true` 表示本次为首喷**，前端需先播「酒精冲洗 2~3 秒」动画再扣减（对应硬件酒精冲洗流程 HW-02）；
- 第 5 喷用完时 Mock 自动把订单置为 `finished`。

### 9. `POST /api/trial/orders/:id/finish` — 完成试香并发券（MP-08）

**入参**：路径参数 `id`。

**返回 data**

```json
{
  "orderId": "TB1001",
  "repeat": false,
  "coupon": {
    "id": "CP1002", "name": "正装立减券", "amount": 3, "threshold": 19,
    "status": "valid", "sourceOrderId": "TB1001",
    "expireAt": 1760604800000, "issuedAt": 1760000000000
  }
}
```

**业务规则**：幂等——重复调用不重复发券（`repeat: true` 返回已有券）。未喷射完也可手动调用（「不喷了直接完成」）。

### 10. `POST /api/trial/orders/:id/refund` — 试香退款（MP-06 / HW-09）

**入参**：路径参数 `id`。

**返回 data**

```json
{ "orderId": "TB1001", "refundAmount": 0.5, "status": "refunded" }
```

**业务规则**：仅 **已支付且未喷射**（`status = paid` 且 `sprayUsed = 0`）可退；已喷射返回 `409`。对应 PRD「支付成功但设备出液失败自动退款 / 当日未使用自动退款」的运营口径，Mock 版由用户手动触发。

## 四、正装购买

### 11. `POST /api/shop/orders` — 创建正装订单（MP-07）

**入参**

```json
{ "fragranceId": "f01", "couponId": "CP1002", "address": "（可选，不传用演示地址）" }
```

**返回 data**

```json
{
  "id": "SP1003",
  "fragranceId": "f01", "fragranceName": "晨雾柑橘", "emoji": "🍊", "grad": ["#f6b56b", "#f48c5e"],
  "price": 19.9, "discount": 3, "couponId": "CP1002", "payable": 16.9,
  "address": "河北师大新校区 · 6 号宿舍楼 · 传达室代收（演示地址）",
  "deliveryType": "campus",
  "status": "pending_pay",
  "createdAt": 1760000000000
}
```

**业务规则**：券必须 `valid` 且 `price ≥ threshold`，否则 `409/404`；`couponId` 传 `null` 不用券。

### 12. `POST /api/shop/orders/:id/pay` — 正装支付（MP-07）

**入参**：路径参数 `id`。

**返回 data**：完整正装订单，支付后 `status: "paid"`、`paidAt`，同时**核销优惠券**（`coupon.status → used`）。

**Mock 说明**：默认成功；`TODO(wx)` 同接口 6。

## 五、订单与优惠券

### 13. `GET /api/orders?type=trial|shop` — 订单列表（MP-09）

**入参**：Query `type`（`trial` 默认 / `shop`）。

**返回 data（type=trial）**

```json
[
  { "id": "TB1001", "fragranceName": "晨雾柑橘", "emoji": "🍊", "grad": ["#f6b56b", "#f48c5e"],
    "amount": 0.5, "sprayUsed": 5, "sprayTotal": 5, "status": "finished", "createdAt": "2026-09-18 19:30" }
]
```

**返回 data（type=shop）**

```json
[
  { "id": "SP1003", "fragranceName": "晨雾柑橘", "emoji": "🍊", "grad": ["#f6b56b", "#f48c5e"],
    "payable": 16.9, "status": "paid", "createdAt": "2026-09-18 19:42" }
]
```

**Mock 说明**：按创建时间倒序；`createdAt` 已格式化为 `YYYY-MM-DD HH:mm` 字符串。

### 14. `GET /api/coupons` — 我的优惠券（MP-08）

**入参**：无。

**返回 data**

```json
[
  { "id": "CP1002", "name": "正装立减券", "amount": 3, "threshold": 19, "status": "valid", "expireAt": "2026-09-25" }
]
```

**字段说明**：`status`：`valid` 可用 / `used` 已使用 / `expired` 已过期；`expireAt` 已格式化为日期字符串。

### 15. `POST /api/dev/reset` — 重置演示数据（演示专用，非正式接口）

**入参**：无。**返回 data**：`{ "reset": true }`。

**Mock 说明**：清空 localStorage 恢复初始库。**接真实后端时删除此接口及前端「重置演示数据」入口。**
